Abstract

Personally Identifiable Information (PII) remains a persistent privacy and security concern for both individuals and organizations. The widespread adoption of Large Language Models and AI Agents introduces new threat vectors: sensitive data is not only pasted by users into chat interfaces, but also accessed by agents, increasing the risk of unintended leakage. Traditional PII detection systems, based on static rules and patterns, lack contextual understanding and remain inherently limited. More advanced pre-trained models, including Small Language Models, add contextual reasoning but have complementary failure modes to pattern detectors, leaving both families vulnerable in isolation.

We develop a taxonomy of inference-time attacks and release AdvPIIBench, a dataset of synthetic but realistic user prompts containing high-risk PII types such as IBANs, SSNs, and credit-card numbers, generated via an LLM-guided pipeline. We systematically evaluate rule-based, transformer-based, SLM-based, and LLM-based detectors on this dataset, showing that detection recall can collapse to zero under adversarial conditions.

The transformations

Red-Teaming · attacks the value

PII Sculpting

The value itself is rewritten. Every form below still reads as a card number to a person, and every one is produced by the benchmark’s own attack code.

Red-Teaming · attacks the cue

Contextual PII Sculpting

Implemented as supportive_context. The value is left completely untouched — only the PII indicator that announces it is transformed, so detectors leaning on that cue lose their anchor.

Template-Based · attacks the framing

Affix Injection and Prompt Injection

Neither the value nor its cue is touched. These are wrappers placed around the whole prompt, aimed at the detector rather than the user’s request.

Neural Prompt-to-Prompt · attacks by rewriting

An agent that rewrites until it gets through

The attacker is an LLM holding the prompt, a tactic list and a target detector. It rewrites, tests, and rewrites again — composing techniques across rounds instead of applying one. We release this as an adaptive red-teaming procedure; unlike the static techniques above, no attack-success rate is claimed for it.

What the benchmark shows

01

Orthogonal collapse

Every detector family has an attack that drives its recall to near-zero — and the attacks that break one family leave another untouched.

02

No family is safe alone

Across 13 detectors, every one has at least one configuration that drives it to near-zero. No single system holds up alone; robustness needs complementary families combined.

03

Recall alone is not enough

The ranking inverts on hard, PII-lookalike negatives: the OpenAI Privacy Filter leads on clean recall at 97.4% and also leads on false positives at 58.5%. Recall and false-positive rate have to be read together.

04

One sentence undoes the best detector

GPT-4o-mini is the strongest detector tested — 99.8% recall on clean prompts, and still 96.0% once the card number is sculpted. Prepend a single line of plausible framing and the same model reports no PII at all.
